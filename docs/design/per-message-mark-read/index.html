规则

显隐：.dtn-ni:hover、:focus-within 显示；触屏与 <640px 常驻。
只服务未读：已读行不渲染按钮，右侧只有时间。
点按钮不点行：stopPropagation + 行 handler 的 target 守卫，Enter / Space 同理。
文案：复用 action.markRead（标为已读 / Mark read），只出现在 aria-label 与 title，不新增 key。
不改：色条、未读点、字重、分隔线、行高（44–62px）、点开跳转的行为。
